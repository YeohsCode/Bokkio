# 操作录制修正实测

2026-10-15。Shortcuts 录制应用操作并生成 Workflow，回放重新执行应用操作。撤回视频采集、播放器和视频时间线；不保留视频数据兼容分支。

## 修正与副作用

- 删除 capture renderer、MediaRecorder、WebM 封装、媒体协议、视频 IPC、屏幕源选择和视频配置。
- 从 Workflow 步骤及录制元数据移除视频字段；不做迁移或兼容。录制元数据只接受操作录制开始时间。
- 保留操作时间戳和回放间隔/速度、原生控件身份、窗口上下文、系统输入与按需图像锚点。
- 普通操作录制直接启动原生事件捕获器，不查询屏幕源、不创建隐藏采集窗口、不等待视频封装。
- 按钮和全局快捷键停止都进入相同的补录合并路径。补录保留原 Workflow 身份和首步断点、避免应用别名覆盖，并调整后续操作时间。
- 非连续选择不能补录；空补录保留原步骤；紧急停止后不会重新显示上一次运行。修改可撤销。
- 更新当前计划、桌面用法与已安装的应用。图像锚点仍是单张控件截图的定位功能。

## 验证

Python 全量回归 **672/672**；补录数据回归 **3/3**；TypeScript/Vite 构建通过。

实际界面使用 Electron 产品窗口。演示输入由测试驱动产生真实 OS 鼠标/键盘事件；不是人工演示，也不是浏览器原型点击。测试先清空目标文档，再回放，并通过独立原生读取检查最终内容。

macOS 操作录制专项 **14/14**，实际结果见 `macos-operation-ui.json`。Windows 最终安装版专项 **17/17**，见 `windows-packaged-operation-ui.json`。两平台专项结果分别保存在相邻 JSON。macOS 的额外测试将 Electron 屏幕源枚举和 renderer 屏幕采集接口改为抛错，验证普通操作录制不依赖它们。macOS 编辑器另实测复制、撤销/重做、断点、单步、整段回放及归档恢复。Windows 安装版实测配置/对话页面、录制、热键暂停/继续/停止、步骤编辑、断点/单步、补录、保存、回放和独立 Notepad 读回。

包内检查验证已删除的采集/封装文件不在 app.asar 中，main/preload 与当前源码一致，Python 数据模型不接受视频字段。macOS 安装版只验证启动与实际界面；其原生输入仍需要该安装应用的系统授权，本轮没有修改系统权限。
