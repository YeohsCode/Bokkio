## 已修复与实际限制

- 原生菜单叶子绑定真实 AXPress；AXDocument 精确路径区分同名文档。原生前台、焦点及主窗口状态每次重新读取，锁屏时停止。
- 原生字段输入校验身份、旧值、边界及点击后的真实焦点。字体弹窗的 Asian text font 使用有界剪贴板粘贴与 Tab 提交；只恢复仍由本次操作持有的剪贴板版本。单独读回字体草稿不证明文档格式。
- Word Paragraph 的 At: 原生 AXValue 是数值类型。旧字符串 setter 会改变属性类型；最新路径以实际 AXTextField 身份、旧值、窗口和焦点校验后编辑，并以 Tab 提交。通用字符串 setter 在数值属性上拒绝派发。
- Word Clear Formatting 的 AXPress 已实机复现只切换按钮而未改变格式；新增一次受保护鼠标点击，派发前绑定按钮 CF 身份、真实焦点内的编辑区、精确选区和窗口。独立探针从 12pt 变为 11pt 并保存；不算完整模型任务通过。
- Word 先精确选正文，清除普通正文的旧直接格式，再单独修改 Asian text font；独立 GUI 探针保存后通过。标题与正文必须分别选区。最新执行器拒绝空选区格式化，Planner 不得把取消标题选区当作正文选择。
- Word pilot 将单页原生文本的首段与其余段落声明为标题/正文选区目标；计划规范化只绑定当前唯一原生文本，不使用答案常量。插入的选区步骤仍通过 Jev/执行器并计入动作预算；已匹配的选区无需重复输入。Styles 的样式名条件只能绑定实际观察到的样式 radio 选项。
- 新控件获取阶段只执行到打开下拉/弹窗，后续字段步骤延迟到重新观察；打开的新原生弹窗可触发阶段观察，不重发别名命令。
- 应用菜单命令使用应用观察范围；派发前确认前台和唯一的已授权主文档。原地保存事实仅来自源文件与目标文件一致的已绑定任务。
- 保存弹窗已可见且有可写文件名字段时，不再重开 File/Save As。
- PPT 视觉范围增加可选精确源文件路径，激活保留文件路径、窗口 ID 和标题，避免同名窗口歧义；绑定进入恢复合约。
- 两个快照探针发现 Word 后台校对更改无名称状态按钮的说明；语义哈希忽略相应说明和 AXHelp，仍绑定身份、名称、状态、几何、选区与实际输入能力。
- 阶段重规划保留前一计划的待办子任务；拒绝用静态 menu.enabled 证明菜单打开。Save As 与 Save 的前缀歧义已修复，尚需完整任务保存验收。
- PowerPoint 标题输入结束后退出编辑，真实 Agent 已验证 Alpha Initiative；原生菜单/保存弹窗保持原生路径。空白 scratch 的另建未绑定文档入口已排除。
- 混合路径可由原生动作触发 OCR 后置验证。未知完成只读核对一次，成功条件从假变真才继续，绝不重发未知输入。零派发过期错误可在原预算内重新观察。
- Font 子弹窗的直接 ScreenCaptureKit 像素映射尚不可靠；选项输入使用父字体窗口捕获、实际原生选项边界、所属视口与命中核对。通用子弹窗映射仍待扩展。

PPT 初始化只生成隔离 desktop 内的零页空白文件，不预置标题或目标输出。保存由 GUI 完成。这是 Mac 适配验收，独立只读 OOXML 评分不等于官方分数。
