## macOS 续测（2026-10-12）

- 五项真实作业故障 **5/5**：取消、超时、关闭会话终止进程树；worker SIGKILL 后转未知完成且原 ID 不重发；stdout/stderr 持续读取并截断。
- 实机窗口/作业矩阵 **16/18**（其中桌面检查 11/13）：移动、缩放、像素变化、前台接管、同名重建后的旧引用、真实 15 秒过期、锁等待期间关会话、同名歧义、进程退出、最小化通过。两项正向点击受系统通知前台守卫零派发拒绝，尚未补足。
- 新增不依赖 vendor 的 Cocoa 原生 fixture；原生字段、代码、Browser 各 **3/3**，MCP/CLI、审批及日志对账通过。
- 新增通用 MCP task manifest runner 与单次 MCP 调用示例；中文字段三轮 **3/3**，审批只由独立本地管理员入口处理。
- Numbers 自主开发样本 **3/3**：MCP 生成/打开本机 CSV、按观察到的 ref 写入工作表名称字段、独立读回和源哈希检查；Core 没有新增 Numbers 业务规则。当前 Codex 为调用方，测试管理员审批，不能计作客户选定应用/Harness 或客户人工审批。
- 审批状态查询现在自动记录已经到期的 pending/approved 申请，避免界面仍显示 pending；事件不重复，限制在请求 session。

所有分轮及失败见 [本轮证据](../evidence/2026-10-12-runtime-macos/README.md)。只有一个物理显示器、scale=1；锁屏/解锁及第二显示器/不同缩放未验收。
